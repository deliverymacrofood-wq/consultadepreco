Importar CSV

Importe uma planilha CSV com cabeçalhos: codigo,nome,codigo_barras,varejo,atacado. Valores decimais podem usar vírgula.

Importante sobre vários dispositivos

Esta primeira versão funciona offline e guarda os dados localmente em cada aparelho. Para todos os aparelhos compartilharem automaticamente o mesmo catálogo pela internet, será necessário conectar um banco de dados online (por exemplo, Supabase). Até isso ser configurado, use exportar/importar para transferir os produtos.
