IMPORTANTE: DADOS LOCAIS E SINCRONIZAÇÃO
Esta versão guarda os produtos no armazenamento local do navegador de cada dispositivo. Isso permite uso offline, mas não sincroniza automaticamente celulares e computadores entre si. Para sincronizar, será necessário configurar um banco de dados online e autenticação (por exemplo, Supabase). Até essa integração ser feita, transfira o catálogo com Backup/Importar.

COMO ABRIR NO COMPUTADOR
1. Extraia o ZIP para uma pasta.
2. Para teste simples, abra index.html. Cadastro e busca manual funcionam; a câmera e o modo offline instalável podem exigir servidor local.
3. Para usar câmera e PWA com segurança, publique em um site HTTPS ou rode um servidor local. No Windows com Python instalado, abra o Prompt dentro da pasta e execute:
   python -m http.server 8000
   Depois abra http://localhost:8000
   Para a câmera, use um navegador compatível e permita acesso.

COMO USAR NO CELULAR
1. Publique a pasta em um endereço HTTPS (hospedagem estática).
2. Abra o endereço no Chrome/Edge/Safari compatível.
3. Permita acesso à câmera ao tocar em “Abrir câmera e ler código”.
4. Para instalação como app, use “Adicionar à tela inicial”/“Instalar aplicativo” quando o navegador oferecer.
5. Abra uma vez com internet para carregar os arquivos; depois o app pode abrir offline. A disponibilidade da câmera offline depende do navegador e das permissões.

IMPORTAR CSV
Cabeçalhos aceitos incluem:
codigo,nome,codigo_barras,varejo,atacado
Também são aceitos nomes como código, produto, ean, valor_varejo, valor_atacado.
Use uma linha por produto. Evite salvar códigos como números com notação científica. O código interno deve ter no máximo 6 dígitos.

LIMITAÇÕES CONHECIDAS
- O leitor usa BarcodeDetector, disponível principalmente em navegadores Chromium recentes; não é suportado em todos os navegadores. Se não aparecer suporte, use busca manual.
- Abrir a câmera exige HTTPS ou localhost na maioria dos navegadores.
- Não há login nem sincronização multiusuário nesta versão inicial.
- Não use o app como única cópia dos seus preços: exporte backups regularmente.

CATÁLOGO IMPORTADO
O catálogo incluído foi extraído do PDF TODOS OS PRODUTOS(1).pdf: 487 produtos, com código reduzido, código de barras, nome, marca estimada a partir do nome e P.Venda. Nas páginas 24 a 49, P.Venda foi dividido por Qt. Unit., conforme a regra solicitada anteriormente. O PDF não apresenta um campo explícito de preço de atacado; P.Tabela coincide com P.Venda nos registros analisados, então o atacado fica vazio quando não há um valor diferente. Confirme os valores de atacado na fonte original se precisar preencher esses preços.
